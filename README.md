# Smart IoT Patient Monitoring System

## Overview
The **Smart IoT Patient Monitoring System** is an innovative solution designed to enhance healthcare management through real-time monitoring of patient health data. This project leverages cutting-edge technologies to empower patients and healthcare professionals alike, enabling continuous health tracking, secure data management, and accessible insights for better healthcare outcomes.

## Tech Stack
- **Backend**: Python with FastAPI
- **Frontend Web**: React + Vite + TypeScript
- **Mobile App**: Flutter
- **Cloud Services**: AWS (Amazon Web Services)

## Features
- **Real-time Health Data Monitoring**: Instantly capture and display health metrics.
- **User-friendly Mobile Application**: Patients can access their health data anytime, with intuitive visuals and alerts.
- **Comprehensive Web Application for Healthcare Professionals**: Easily accessible patient data, analytics, and management tools.
- **Secure Cloud-Based Data Storage and Processing**: Utilizes AWS for reliable and secure data handling.
